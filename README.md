# InternCircle Python Internship – Project 05
## Weather App with Live OpenWeather API

### Description
This project is a Python-based Weather Application that uses the OpenWeather API to display real-time weather information for any city.

### Features
- Search weather details by city name.
- Display current temperature in Celsius.
- Display humidity percentage.
- Show weather conditions.
- Display wind speed.
- Provide a 5-day weather forecast.
- Handle invalid city names and API errors.
- Protect the API key using an environment variable.

### Technologies Used
- Python
- Requests Library
- OpenWeather API
- JSON
- VS Code

### How to Run
1. Install Python.
2. Install the Requests library using `pip install requests`.
3. Set the `OPENWEATHER_API_KEY` environment variable.
4. Run the application using `python weather_app.py`.
5. Enter a city name to view weather information.

### API Key Security
The API key is stored in an environment variable instead of being directly written in the source code. This helps protect the key from being exposed publicly.
